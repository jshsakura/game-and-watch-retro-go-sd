# Coverage denominator for tests/coverage.sh.

# "Coverage of the whole tree" is meaningless here: the tree is mostly ST HAL
# drivers, 29 third-party emulator cores, and LCD/SAI/SD peripheral code that
# cannot run on a host at all. This file is the list of what CAN run on a host
# AND is ours to fix, built from two things: what tests/run.sh already
# compiles, and what has actually shipped broken (git log — see root
# CLAUDE.md's "Debugging crashes on hardware" section and the fix(*) commits).
#
# Format: STATUS<TAB>path<TAB>reason. Blank lines and lines starting with #
# are ignored. Paths are relative to the repo root; EXCLUDED entries may be a
# directory prefix (matched by startswith) instead of a single file.
#
# STATUS:
#   MEASURED   tests/coverage.sh compiles the REAL file with --coverage and
#              runs a binary that exercises it (mirrors tests/run.sh). The
#              number in the report for this file came from an actual run.
#   UNMEASURED code we own, and nothing in its own body rules out a host
#              build (grep for HAL_/SAI_/DMA_/SPI_/GPIO_ calls was the first
#              filter) — but no test compiles the real file today, so
#              tests/coverage.sh reports "NO HARNESS", not 0%. 0% would claim
#              a measurement that was never taken. This list IS the work
#              order the task asked for; priority notes are in the reason.
#   EXCLUDED   out of the denominator, with why.
