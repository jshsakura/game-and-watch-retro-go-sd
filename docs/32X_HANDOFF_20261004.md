## 다시 밟지 말 것

- **히스토그램의 `dropped`를 먼저 본다.** 예전 해시는 PC 하위 비트를 그대로 써서 명령의 45%까지
  버렸고, Kolibri 슬레이브와 Chaotix, Virtua Fighter의 "실제 연산이라 불가" 판정이 그 표에서 나왔다.
  지금은 곱셈 해시다. `dropped 0`이 아니면 상위 목록을 믿지 않는다.
- **리그 창과 장치 창이 같은 장면인지 확인한다.** Kolibri 패치는 리그 300프레임(부팅 구간)에서
  −28%였고 장치 게임 장면에서는 0이었다. `-DRIG_HIST_FROM=<frame>`으로 게임 장면만 집계한다.
- **fastloop에 넣는 접기는 `noinline` 별도 함수로.** 인라인되면 인터프리터 전체가 느려진다(접기 0회에 +14%).
- **자리가 없다.** ITCM 여유 112바이트, RAM_EMU 528바이트. 새 함수는 SDRAM을 직접 읽어 작게 쓰고,
  프레임당 호출이 적으면 `section(".gnw_xip_cold")`로 XIP에 둔다. 빌드 전에 `nm -S`로 크기를 본다.
- **장치는 10분 유휴에 꺼지고 SWD로 못 깨운다.** 설치나 재부팅 직후마다 `keepalive.sh on`. 값을 읽지
  못하면(`was s`) 장치가 꺼졌거나 gnwmanager 헬퍼 상태다. `sdpull`/`sdpush`/`info` 뒤에는 `start bank2`.
- **소리는 볼륨 1로.** 게임 시작 뒤 첫 프레임 루프에서 `odroid_audio_volume_set 1`을 호출한다. 시작 전에
  RAM 값을 바꾸면 되돌아간다. 음소거는 하지 않는다. 끝나면 8로 되돌리고 `/CONFIG`를 원본과 비교한다.
- 호스트에 `arm-none-eabi-gcc`가 없다. `/home/pi/scratch/bin`의 docker 래퍼를 PATH 앞에 둔다.
